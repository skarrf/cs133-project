# cs133-project

Project Title: Does plane seat location affect survivability?

Authors: Patrick

Project Description (5 Sentences):
This project will see if plane seat location has an affect on survivability during a crash. The data will come from an existing dataset comparing seat survival rates of 5 plane crashes (more could be included). The Boeing 737 is focused on because it's the most common commercial aircraft. The dataset will include variables such as seat location, passenger outcome, aircraft model, accident conditions, etc. THe goal is to see if certain seats or if any seats have a factor in surviving.

Project Outline/Plan:

1. Interface Plan:

2. Data Collection and Storage Plan (written by Author #1):
   I will collect initial data of seat survivability from a dataset. It will include relevant information such as flight, date, aircraft model, passenger seat locations, survival outcomes, etc. The dataset will be cleaned beforehand for analysis.

3. Data Analysis and Visualization Plan (written by Author #2):
   I will also do the data cleaning, exploratory data analysis, and statistical testing using Python and its libraries. The analysis will see if passenger seating affects survival. Visualizations may include bar charts of survival rates or comparisons between cabin sections for each of the planes. I will conduct an appropriate inferential statistical test, such as a chi-square test of independence between cabins. The final analysis will discuss the small amount of data and differences between crashes.
